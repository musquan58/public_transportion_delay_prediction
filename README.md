# Public Transport Delay Prediction System

Advanced Web Technologies mini project.

## Technologies
- HTML, CSS, JavaScript
- Bootstrap
- Python Flask
- SQLite
- Fetch API / JSON
- Chart.js

## Run
Open this folder in VS Code, then:

    pip install -r requirements.txt
    python app.py

Open: http://127.0.0.1:5001
